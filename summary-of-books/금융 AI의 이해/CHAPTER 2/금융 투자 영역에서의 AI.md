# CHAPTER 2 금융 투자 영역에서의 AI

## 2.1 대표적인 금융 투자 방식

#### 금융 투자

개인이나 기업이 돈을 다른 사업이나 자산에 투자하는 것

#### 퀀트 투자

데이터와 수학적 모델을 기반으로 투자 전략을 설계하고, 이를 체계적으로 실행하는 방법

#### 알고리즘 트레이딩(시스템 트레이딩)

사전에 정의된 규칙 또는 수학적 모델을 기반으로 컴퓨터가 금융 시장에서 자산을 자동으로 매매하는 방식

---

### 2.1.1 퀀트의 기원과 AI 시대

#### 투자 전략의 발전 과정

| 투자 전략        | 설명                                                                                     |
| ---------------- | ---------------------------------------------------------------------------------------- |
| 추세 추종 시스템 | 시장을 예측하기보다 가격이 오르면 따라 사고, 내리면 파는 방식으로 추세에 대응하는 전략   |
| 정량 주식 선택   | 재무 데이터와 통계 알고리즘을 활용하는 투자 방식                                         |
| 스마트 베타      | 시가총액 대신 가치, 배당 등 특정 기준을 활용해 종목을 골라 투자하는 방식                 |
| 고빈도 거래      | 초고속 알고리즘으로 아주 짧은 시간 동안 매매를 반복하며 작은 가격 차이로 수익화하는 방식 |
| AI 도구 활용     | 머신러닝·딥러닝을 이용해 데이터 분석과 투자 전략을 개선하는 방식                         |

---

## 2.2 금융 투자 영역에서 AI가 각광받는 이유

#### 컴퓨팅 속도

대규모 금융 데이터를 빠르게 처리 가능

#### 데이터 및 오픈소스 발전

- 라이브러리 발전으로 데이터 분석 및 모델 개발이 쉬워짐
- 정형 + 비정형 데이터를 동시에 분석하기 위해 머신러닝과 딥러닝이 필수화됨

---

## 2.3 AI를 접목한 투자의 장점과 단점

#### 장점

감정적 편향을 배제한 체계적인 투자 가능

#### 단점

- **과적합 문제 및 유연성 부족**: 과거 데이터에 의존해 변화하는 시장에 적응이 어려울 수 있음
- **윤리적 문제**: 데이터 수집 과정에서 개인정보 침해 가능성 존재

<aside>

    - 과적합(Overfitting): 머신러닝 모델이 훈련 데이터에 너무 과하게 최적화되어, 학습에 사용되지 않은 새로운 데이터(테스트 데이터)에 대한 예측 능력이 떨어지는 현상

</aside>

---

## 2.4 금융 투자 데이터 유형

#### 투자 데이터 분류

| 데이터 유형     | 설명                                                      |
| --------------- | --------------------------------------------------------- |
| 마켓 데이터     | 금융 시장에서 거래되는 자산의 가격과 관련된 데이터        |
| 펀더멘털 데이터 | 기업의 재무적 건전성과 가치를 평가하는 데 사용되는 데이터 |
| 대체 데이터     | 전통적인 금융 데이터 소스 이외의 정보                     |

#### 투자 데이터의 유용성을 검증하는 기준

- 신뢰성
- 세분화
- 효용성
- 사용 범위
- 행동 가능성
- 희소성

---

## 2.5 데이터 소스 선택

#### 퀀트 투자자들의 경우

- 블룸버그, 로이터 등 유료 데이터 사용
- 신뢰도 높고 고품질 데이터 및 다양한 분석 도구 제공

#### 초기 테스트 단계의 경우

- 무료 또는 오픈 데이터 / 공개 API 활용
- 예: Investing, yfinance, TAIFEX, Kaggle, Tushare, Estimize
- 데이터 특성을 분석하고 목적에 맞게 선택하여 사용

## 2.6 전통적인 퀀트 투자 vs. AI 기반의 계량 투자

|                  | 전통적인 퀀트 투자               | 머신러닝/딥러닝                                  |
| ---------------- | -------------------------------- | ------------------------------------------------ |
| 접근 방식        | 통계적 방법, 규칙 기반 접근      | 데이터 기반 패턴 학습                            |
| 사용하는 데이터  | 구조화된 데이터                  | 구조화 + 대체 데이터, 비정형 데이터              |
| 모델 구축        | 사전에 정의된 규칙이나 가정 기반 | 데이터를 통해 비선형 관계를 학습해 모델화        |
| 예측 방법        | 선형 모델, 시계열 분석 중심      | 다양한 알고리즘으로 비선형 패턴 및 상호작용 학습 |
| 해석 가능성      | 높음 (단순하고 설명 쉬움)        | 낮음 (복잡한 블랙박스 가능)                      |
| 복잡한 패턴 인식 | 제한적                           | 강함                                             |
| 데이터 처리      | 비교적 제한된 데이터             | 대규모·다양한 데이터 처리 가능                   |
| 시장 변동 대응   | 상대적으로 느림                  | 지속 학습으로 더 유연하게 대응 가능              |

<aside>

    - 모델: 현상을 설명하거나 예측하기 위한 구조
    - 시계열 분석: 시간의 흐름에 따라 변하는 데이터를 분석해 미래 값을 예측하는 방법
    - 블랙박스: 입력과 출력은 알 수 있지만, 내부 과정(작동 원리)은 잘 보이지 않는 시스템

</aside>

### 2.6.1 전통적인 퀀트 투자 전략

| 전략             | 설명                                                            |
| ---------------- | --------------------------------------------------------------- |
| 평균 회귀 전략   | 가격이 평균으로 돌아간다는 가정에 기반한 전략                   |
| 추세 추종 전략   | 상승 추세를 따라 매수하고 하락 시 매도하는 전략                 |
| 페어 트레이딩    | 상관관계가 높은 자산 간 가격 차이를 이용하는 전략               |
| 요인 모델        | 가치·모멘텀 등 특정 요인이 수익률에 미치는 영향을 분석하는 모델 |
| 이벤트 기반 전략 | 인수합병 등 특정 이벤트를 기반으로 거래하는 전략                |

<aside>

    - 모멘텀(Momentum): 가격 상승 또는 하락 추세가 일정 기간 지속되는 경향
    - 평균 회귀 전략·페어 트레이딩: 과소평가된 자산은 매수하고, 과대평가된 자산은 매도

</aside>

### 2.6.2 AI 기반 투자 전략

| 전략               | 설명                                     |
| ------------------ | ---------------------------------------- |
| 포트폴리오 최적화  | 수익률과 리스크의 균형을 최적화          |

| 리스크 관리        | 위험 분석 및 손실 최소화 전략 수립       |

## 2.7 AI를 금융 투자에 활용할 때 주의해야 할 점

#### 데이터 편향

- 생존 편향: 시장에서 살아남은 데이터만 분석하여 실패 기업 데이터가 누락되는 현상
- 미래 참조 편향: 과거 데이터 분석에 미래 정보가 포함되는 오류

#### 시계열 데이터의 특성

- 제한된 시계열 데이터로 인해 통계적 유의성 확보가 어려움

#### 과적합 문제

- 훈련 데이터에 지나치게 최적화되어 새로운 데이터 예측 성능이 떨어지는 현상

#### 해석 가능성

- 모델이 복잡할수록 결과 해석이 어려워 실제 투자 환경에서 신뢰성이 낮아질 수 있음

---

## 2.8 실제 투자 영역에서의 AI 응용 사례

#### 위성 이미지 데이터를 활용한 트레이딩 전략

- 위성 이미지와 위치 데이터를 활용해 기업 활동 및 투자 기회를 분석

#### LLM 활용

- 금융 뉴스 분석, 정보 요약, 투자 판단 지원 등에 활용
- 예: 블룸버그 GPT, FinGPT
