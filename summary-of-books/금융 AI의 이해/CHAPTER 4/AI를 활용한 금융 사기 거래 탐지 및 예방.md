# CHAPTER 4 AI를 활용한 금융 사기 거래 탐지 및 예방

## 4.1 금융 사기 거래 탐지의 중요성과 AI

#### 현대 금융 환경의 모습

- 결제 수단 다양화
- 온라인 결제 증가
- 크로스보더 결제 확대

#### 금융 사기 탐지의 필요성

- 익명성과 복잡성 증가로 기존 방식만으로 탐지에 한계 존재
- AI 기반 분석을 통해 이상 거래를 효과적으로 탐지 가능
- 지속적인 학습으로 새로운 사기 유형에 빠르게 대응 가능

---

## 4.2 이상 탐지와 사기 거래 탐지

#### 이상탐지

- 정상 범위를 벗어난 비정상 패턴을 탐지하는 기법

#### 금융 사기 거래 특징

- 과도하게 큰 금액 거래
- 평소와 다른 시간대 거래
- 기존 소비 패턴과 다른 거래 발생

#### 이상 탐지 활용

- 이상 탐지 알고리즘이 비정상 거래를 탐지하여 사기 가능성을 판단

---

## 4.4 금융 사기의 특성

1. 희박함
   - 사기 거래는 전체 거래 중 극소수
   - 사기 거래 탐지 학습 데이터 부족
2. 조직성
   - 치밀하게 계획된 범죄 형태
   - 장기간 복잡한 구조로 진행되기도 함
3. 은밀성
   - 사기 행위를 숨기려 하기 때문에 탐지가 어려움
4. 다양성
   - 다양한 기술과 방식으로 발생
5. 진화성
   - 시간이 지날수록 새로운 형태로 변화
   - 탐지 기술도 지속적인 발전 필요

## 4.6 금융 사기 거래 탐지 및 예방

### 4.6.1 사기 거래 탐지 및 예방 시장 규모

- 클라우드 기술 발전과 모바일 뱅킹 확대로 시장 성장
- 클라우드는 높은 처리 능력과 저장 용량 제공
- 사이버 범죄를 빠르게 추적·분석 가능

---

### 4.6.2 금융 사기 예방 방법

#### 규칙 기반 방법

- 특정 조건을 만족하면 사기로 판단하는 방식
- 예: 짧은 시간 내 반복 결제·인증 실패
- 새로운 사기 유형 등장 시 규칙 수정 필요

#### 데이터 기반 방법

- 통계적 분석 기법 활용
- 머신러닝·딥러닝 기반 탐지 활용

#### 데이터 기반 방법의 장점

| 장점        | 설명                         |
| ----------- | ---------------------------- |
| 정밀도      | 복잡한 사기 패턴 탐지 가능   |
| 운영 효율성 | 실시간 거래 분석 가능        |
| 비용 효율성 | 탐지 과정 자동화             |
| 적응 효율성 | 새로운 사기 유형에 대응 가능 |

#### 남아 있는 과제

- 데이터 부족 문제
- 지연된 피드백과 과적합 문제
- 설명 가능성, 윤리성, 편향성 문제
